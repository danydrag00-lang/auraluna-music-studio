# Implementation status
Initial browser-based foundation only. No verified recordings imported, no listening tests performed. The local importer requires human review of rights; it does not independently validate source claims. No automated remote ingestion, multi-hour export, MP3/FLAC, advanced studio, nature mixing, or deployment yet. Preview composition is rule-based, with exact symbolic duplicate detection only. Full prompt interpretation and genre-specific musical models are not implemented. To run composer tests: node --test tests/composer.test.mjs. To import: python3 scripts/ingest.py --help. Use a local HTTP server to test browser rendering after importing pitch coverage. Do not host large audio libraries in ordinary Git history; migrate the initial local audio directory to appropriate storage before scaling.
